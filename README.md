# kgajulapalli.org

Plain HTML and CSS, no build step, no JavaScript. Everything is styled by `css/site.css`.

- `index.html` — homepage
- `research.html` — publications; copy an `<li>` block to add a paper
- `teaching.html` — courses
- `notes.html` — expository notes
- `discrete_math_f26/` — Fall 2026 course page; add a `<tr>` per lecture
- `papers/`, `slides/`, `expositions/`, `assets/` — PDFs and images

Fonts load from Google Fonts (Source Serif 4) and fall back to Georgia if unavailable.
